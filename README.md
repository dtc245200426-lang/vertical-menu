# Thực hành tạo menu dọc

Menu ACCP i10 gồm Sem 1, Sem 2, Sem 3 và Sem 4. Sem 1 và Sem 2 có danh sách môn học con.

Mở `index.html` bằng trình duyệt. Đưa chuột vào Sem 1 hoặc Sem 2 để hiện menu con bên phải; mục đang được chọn đổi nền từ đen sang đỏ. Có thể dùng phím Tab để mở menu con khi liên kết nhận focus.

CSS dùng danh sách lồng nhau, `position: relative/absolute`, `visibility` và `:hover`. Menu chính rộng 140px gồm nội dung 100px và padding hai bên 20px. Menu con được tăng chiều rộng để tên môn học dài không tràn ra ngoài.

Các liên kết `#` là liên kết minh họa theo đề bài.
